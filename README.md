# LivePace - Interior Design Application

A modern React.js and Node.js application for interior design services, converted from .NET.

## Features

- 🏠 Complete interior design solutions
- 💰 Interactive price calculator
- 📚 Design magazine and articles
- 🏙️ Multi-city service coverage
- 📸 Project portfolio showcase
- 📅 Free consultation booking
- 📱 Fully responsive design

## Tech Stack

### Frontend
- React.js 18
- React Router DOM
- Bootstrap 5
- Font Awesome Icons
- CSS3 with CSS Variables

### Backend
- Node.js
- Express.js
- CORS enabled
- RESTful API

## Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Backend Setup
```bash
cd backend
npm install
npm run dev
